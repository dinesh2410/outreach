# Features

1. **ASO Description Generator** — MVP, building now. Three variant angles (keyword, conversion, brand), both stores, character counters, compare-all view, keyword extraction.
2. **Screenshot Generator + Localization** — Coming soon. Generate store screenshots with text overlays, localize to multiple languages.
3. **Reddit Replies** — Coming soon. Find relevant threads, draft contextual responses.
4. **Competitor Analysis** — Coming soon. Paste your app + competitor URL, get a comparison.
5. **Keyword Research** — Coming soon. Discover and track keywords for your category.
