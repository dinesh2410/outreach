# Outreach

The post-build platform for indie app makers. Everything after "build" — starting with ASO descriptions.

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Tech Stack
- Next.js 16 (App Router, TypeScript)
- Tailwind CSS v4
- lucide-react for icons
- Mock auth and mock data (no real backend yet)

## Project Structure
- `/app` — Pages and layouts
- `/components` — UI components (landing, generator, shared, mocks)
- `/lib` — Utilities, types, constants, mock AI generator
